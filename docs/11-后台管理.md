# Admin Management Specification

Version：V1.0

---

# 一、后台定位

后台仅供管理员使用。

网站所有内容必须通过后台维护。

后台语言：

**中文**

前台语言：

**英文**

---

# 二、登录

管理员登录。

第一版：

* 用户名
* 密码

后期增加：

* 二步验证（2FA）
* 登录日志

# 十、安全

后台：

仅管理员访问。

密码加密存储。

所有操作记录日志（预留）。

后台目录禁止搜索引擎收录。

---

# 十一、开发原则

后台采用：

Bootstrap Admin

响应式设计。

保持简单。

不追求复杂权限。

第一版仅支持一个管理员。

后期再扩展角色权限。
