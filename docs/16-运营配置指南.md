# 二、Bing Webmaster

1. 打开 https://www.bing.com/webmasters
2. 添加站点 `https://sisuu.com/`
3. 验证方式任选：

## 方式 A：XML 文件（Bing 默认）

1. Bing 会提供 `BingSiteAuth.xml`，内容类似：

```xml
<?xml version="1.0"?>
<users>
    <user>xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx</user>
</users>
```

2. **放到项目目录**（不是 `app/static/`，根路径由 FastAPI 路由提供）：

```text
app/verify/BingSiteAuth.xml
```

3. 部署后访问应返回 200：`https://sisuu.com/BingSiteAuth.xml`
4. 回到 Bing 点击验证

> 本地路径：`d:\Laragon\www\sisuu.com\app\verify\BingSiteAuth.xml`

## 方式 B：HTML meta 标签

1. Bing 提供 `<meta name="msvalidate.01" content="..." />`
2. 后台 `/admin/settings` → **Bing 验证 meta** → 粘贴 `content` 里的字符串 → 保存

4. 提交 Sitemap：`https://sisuu.com/sitemap.xml`

## SEO 文章自动同步

运营向长文维护在 `app/data/synced_blog_posts.py`。部署时 `scripts/sync_blog_posts.py` 会按 **slug** 写入/更新 MySQL（无需后台手工粘贴）。

```bash
# 本地或容器内手动执行
python scripts/sync_blog_posts.py
```

`deploy.sh` 与容器 entrypoint 在迁移后会自动跑同步。

# 三、生产 `.env` 安全清单

部署前确认：

| 变量 | 要求 |
|------|------|
| `DEBUG` | `false` |
| `SECRET_KEY` | 随机 32+ 字符，非默认值 |
| `ADMIN_PASSWORD` | 已修改，非 `admin123` |
| `DEEPSEEK_API_KEY` | 已配置，勿提交 Git |
| `DATABASE_URL` | 生产 MySQL 连接串 |
| `MYSQL_ROOT_PASSWORD` | 强密码 |

## 备份 cron

```bash
crontab -e
# 加入：
0 3 * * * APP_DIR=/opt/sisuu_tools bash /opt/sisuu_tools/scripts/backup-db.sh >> /opt/sisuu_tools/logs/backup.log 2>&1
```

验证：`crontab -l | grep backup`

# 四、V1.1 部署命令

```bash
cd /opt/sisuu_tools
git pull
pip install -r requirements.txt
alembic upgrade head
python scripts/seed_db.py    # 仅首次或空库
docker compose -f docker-compose.prod.yml up -d --build
```
