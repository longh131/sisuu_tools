# 05-单工具页面规范.md

# Single Tool Page Specification

Version：V1.0

---

# 一、目的

所有工具页面必须使用统一模板开发。

无论是：

* AI 工具
* Calculator
* Policy
* Checker
* Generator
* Converter

全部使用同一套页面布局。

目的：

* 统一UI
* 统一SEO
* 提高开发效率
* 提高维护效率
* 提高Google收录质量

以后新增100+工具，不允许重新设计页面。

---

# 二、页面结构

所有工具页面统一如下：

```text
Header

↓

Breadcrumb

↓

Tool Title(H1)

↓

Tool Description

↓

Tool Form

↓

Generate / Calculate Button

↓

Result Area

↓

AI Analysis（可选）

↓

How It Works

↓

FAQ

↓

Related Tools

↓

Footer
```

---

# 三、Header

保持与首页一致。

包含：

* Logo
* Navigation
* Search
* About

整个网站统一 Header。

---

# 四、Breadcrumb

示例：

```text
Home

>

Calculators

>

Amazon Fee Calculator
```

方便SEO。

---

# 五、标题(H1)

每个页面只能有一个H1。

例如：

Amazon Fee Calculator

Negative Review Reply Generator

VAT Calculator

---

# 六、工具简介

标题下方显示：

一句话介绍。

例如：

> Calculate your Amazon selling fees instantly.

长度建议：

30~80个英文字符。

---

# 七、工具输入区域

统一采用 Card。

包含：

输入框

下拉框

Radio

Checkbox

按钮

布局统一。

桌面端：

左右排列。

移动端：

上下排列。

---

# 八、主按钮

按钮文字根据工具自动变化。

例如：

AI：

Generate

Calculator：

Calculate

Policy：

Search

按钮颜色统一。

禁止不同页面不同颜色。

---

# 九、结果区域

点击按钮后显示。

默认隐藏。

生成完成自动展开。

支持：

复制结果

重新生成

清空

以后支持导出PDF（预留）。

---

# 十、AI Analysis（可选）

仅AI工具或计算器需要。

例如：

利润计算完成：

AI分析：

* 利润是否合理
* 风险提示
* 优化建议

Policy工具：

AI解释官方规则。

如果工具无需AI，则隐藏该区域。

---

# 十一、How It Works

所有工具必须包含说明。

统一三步：

Step 1

输入数据

↓

Step 2

点击按钮

↓

Step 3

获得结果

方便SEO。

---

# 十二、FAQ

每个工具至少：

5个FAQ。

必须与工具相关。

支持：

FAQ Schema。

例如：

What is Amazon Fee Calculator?

How accurate is this calculator?

Is this tool free?

Do I need to register?

How often is data updated?

---

# 十三、Related Tools

页面底部推荐：

4~6个相关工具。

例如：

Amazon Fee Calculator

↓

推荐：

* Profit Calculator
* VAT Calculator
* Shipping Calculator
* ROI Calculator

形成内链。

---

# 十四、SEO要求

每个工具必须：

Title

Meta Description

Canonical

Open Graph

Twitter Card

H1

Structured Data

FAQ Schema

Breadcrumb Schema

不得遗漏。

---

# 十五、URL规范

统一：

```text
/tools/tool-name
```

例如：

```text
/tools/amazon-fee-calculator

/tools/fba-profit-calculator

/tools/vat-calculator

/tools/negative-review-reply-generator
```

禁止：

?id=

?page=

?action=

等动态参数。

---

# 十六、性能要求

页面：

首次加载 ≤2秒。

Google PageSpeed：

≥90。

所有图片采用SVG。

禁止引入无用JS。

---

# 十七、交互规范

提交按钮：

点击后立即进入Loading。

按钮禁用重复点击。

AI生成时：

显示：

Generating...

Calculator：

立即计算。

失败：

显示友好错误提示。

禁止浏览器默认报错。

---

# 十八、统一组件

整个网站所有工具页面必须复用统一组件：

* Header
* Footer
* Breadcrumb
* Card
* Form
* Button
* Result Box
* FAQ
* Related Tools

禁止重复开发。

---

# 十九、统一开发模式

以后新增任何工具：

第一步：

创建配置。

第二步：

填写：

* Tool Name
* Description
* Fields
* Button Text
* FAQ
* Related Tools
* SEO

第三步：

自动生成工具页面。

不得重新编写页面结构。

---

# 二十、第一版工具列表

第一阶段统一采用本模板开发以下工具：

### AI Tools

* Negative Review Reply Generator
* Product Description Generator

### Calculators

* Amazon Fee Calculator
* FBA Profit Calculator
* VAT Calculator
* Shipping Calculator

以后所有新增工具必须100%遵循本规范，不允许单独设计页面，不允许修改页面布局，不允许破坏统一UI和SEO结构。

本规范是整个 Seller Toolkit 网站所有工具页面的唯一开发标准。
