# Database Design

Version：V1.0

---

# 一、数据库

V1.0 使用 MySQL 8。

业务代码不得依赖数据库类型。

开发环境：
Laragon + MySQL 8

生产环境：
Docker + MySQL 8
---

第一版建立以下数据表：

```text
tool_categories
```

# 九、数据库原则

所有数据库操作统一封装。

禁止 SQL 写入页面。

禁止重复查询。

业务层与数据库层完全分离。

---

# 十、数据初始化

首次启动自动初始化：

* 工具分类
* 默认工具
* FAQ
* 网站配置

无需手动导入SQL。
