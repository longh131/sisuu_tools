# 三、技术方案

## 用户认证

- **方式：** Session（与现有 Admin 一致）
- **密码：** passlib bcrypt
- **Session keys：** `user_id`, `user_tier`（登录时从 DB 刷新）

## 支付（PayPal 推荐，Stripe 可选）

- **PayPal Subscriptions** — 无需 Stripe，适合全球卖家
- **Stub** — 未配置时 Contact 候补
- **后台手动 tier** — PayPal 线下收款 / 支付宝个人转账后手动升级

环境变量见 `docs/15-支付方案.md`

## 后台 CRUD

- 工具：name, slug, category, description, is_ai, status, sort_order
- 文章：title, slug, content(Markdown/HTML), category, tags, SEO, published_at
- 删除为软删除（status=false / published_at=null）

# 五、部署说明

1. 拉取 V1.1 代码：`git pull`
2. 迁移：`alembic upgrade head`
3. 初始化数据：`python scripts/seed_db.py`
4. 配置 Stripe 环境变量（可选，不配则仍为候补模式）
5. 重启 Docker：`docker compose -f docker-compose.prod.yml up -d --build`
