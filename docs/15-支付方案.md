# 15-支付方案.md

# Seller Toolkit — 支付方案设计

Version：V1.1 Sprint 4  
适用：**无 Stripe 账户** 的独立开发者 / 小团队

---

# 一、推荐方案（按优先级）

| 优先级 | 方案 | 适合场景 | 你需要什么 |
|--------|------|----------|------------|
| ⭐ **1** | **PayPal 订阅** | 英文站、全球卖家、已有 PayPal 商业账户 | PayPal Developer 应用 + 订阅 Plan |
| **2** | **后台手动升级** | 过渡期、线下收款、验证付费意愿 | 无需支付平台（已实现） |
| **3** | Stripe | 有 Stripe 账户、欧美信用卡为主 | Stripe 账户（代码已支持） |
| **4** | 支付宝 | 主要面向中国大陆用户 | **中国主体** + 支付宝开放平台商户 |
| 备选 | Paddle / Lemon Squeezy | 不想自己处理税务/合规 | 平台审核通过即可 |

**sisuu.com 定位：** 英文 Seller Tools → **PayPal 是最佳选择**，与 Amazon/eBay 卖家支付习惯一致。

---

# 二、为什么不用 Stripe？

你没有 Stripe 账户 **完全没问题**。当前架构：

```text
PAYMENT_PROVIDER=paypal | stripe | stub
         ↓
   PaymentProvider 接口（统一 Checkout + Webhook）
         ↓
   升级 users.tier → pro / business
```

未配置任何支付时 = `stub` 模式，Upgrade 跳转 Contact 收集意向。

---

# 三、PayPal 接入步骤（推荐）

## 1. 注册 PayPal 商业账户

https://www.paypal.com/business

## 2. 创建 Developer 应用

https://developer.paypal.com/dashboard/

- 创建 App → 获取 **Client ID** + **Secret**
- Sandbox 先测，上线改 `PAYPAL_MODE=live`

## 3. 创建订阅 Plan（Products & Plans）

在 PayPal Dashboard 创建两个订阅计划：

| 计划 | 价格 | 对应 env |
|------|------|----------|
| Pro | $19/月 | `PAYPAL_PLAN_PRO=P-xxx` |
| Business | $49/月 | `PAYPAL_PLAN_BUSINESS=P-xxx` |

## 4. 配置 Webhook

URL：`https://sisuu.com/api/billing/webhook`

事件：
- `BILLING.SUBSCRIPTION.ACTIVATED`
- `BILLING.SUBSCRIPTION.CANCELLED`

记录 Webhook ID → `PAYPAL_WEBHOOK_ID`

## 5. 服务器 `.env`

```env
PAYMENT_PROVIDER=paypal
PAYPAL_CLIENT_ID=你的ClientID
PAYPAL_CLIENT_SECRET=你的Secret
PAYPAL_MODE=sandbox          # 上线改 live
PAYPAL_PLAN_PRO=P-xxx
PAYPAL_PLAN_BUSINESS=P-xxx
PAYPAL_WEBHOOK_ID=xxx
```

重启 Docker 后，Pricing 页 Upgrade 按钮会跳转 PayPal 订阅确认页。

> **逐步配置（Sandbox 截图式说明）：** 见 **`docs/17-PayPal-Sandbox配置指南.md`**

# 四、支付宝可以吗？

**可以，但不作为首选。**

| 因素 | 说明 |
|------|------|
| 用户群 | sisuu.com 英文站，主要流量来自 Google / 欧美卖家 |
| 开通门槛 | 支付宝国际/跨境通常需要 **中国大陆企业主体**、ICP 等 |
| 技术 | 需单独实现 `AlipayProvider`，接口与 PayPal 不同 |
| 建议 | 若未来中国大陆流量 >30%，再开 Sprint 加 Alipay |

**过渡期替代：** 中国用户可 Contact 留言 → 你在后台 **手动升级 tier**（`/admin/users/{id}/edit`）。

# 五、无支付平台的运营闭环（现在就能用）

```text
用户点击 Upgrade
    ↓
Contact 表单 / Email 收集（stub 模式）
    ↓
你收到 PayPal 转账 / 微信 / 支付宝个人收款
    ↓
后台 → 用户管理 → 编辑 → tier 改为 pro / business
    ↓
用户刷新账户页，AI 额度立即生效
```

这适合 **V1.0~V1.1 验证期**，不必等支付 API 全部打通。

# 七、决策建议

**你现在应该：**

1. 继续用 **stub + Contact + 后台手动升级** 收集付费意愿（零成本）
2. 有空时注册 **PayPal 商业账户**，按第三节配置（1~2 小时）
3. **暂不做支付宝**，除非明确要做中文站或国内推广

**不要：** 为了「完整」而强行接 Stripe——你不需要。

---

*支付模块遵循 Provider 模式，后续加 Alipay 只需新增 `alipay_provider.py` + env，不改业务层。*
