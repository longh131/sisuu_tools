# 03-UI设计规范.md

# UI Design Specification

Version：V1.0

---

# 一、设计目标

整体风格参考国外优秀 SaaS 工具网站。

要求：

* 简洁
* 专业
* 高级
* 快速
* 易读
* SEO 友好

避免复杂动画和花哨设计。

用户打开网站 3 秒内知道网站是做什么的。

---

# 二、整体风格

风格定位：

> Modern + Minimal + SaaS

关键词：

* Clean
* Professional
* Fast
* Trustworthy

整体视觉偏欧美风格。

---

# 三、颜色规范

主色：

```
#2563EB
```

辅助色：

```
#0F172A
```

成功：

```
#22C55E
```

警告：

```
#F59E0B
```

错误：

```
#EF4444
```

背景：

```
#FFFFFF
```

浅灰背景：

```
#F8FAFC
```

边框：

```
#E5E7EB
```

整个网站颜色不得超过 5 种主色。

---

# 四、字体

统一：

Google Fonts

```
Inter
```

备用字体：

```
Arial

Helvetica

sans-serif
```

不得混用字体。

---

# 五、页面宽度

最大宽度：

```
1280px
```

内容区域：

```
1200px
```

自动居中。

移动端自适应。

---

# 六、Header

固定顶部导航。

包含：

* Logo
* Tools
* Calculators
* Policy
* Blog
* Search
* About

右侧预留：

Login（后期）

导航保持极简。

---

# 七、Hero 区域

首页第一屏必须包含：

主标题（H1）

一句价值描述

搜索框

两个按钮：

```
Explore Tools

Popular Tools
```

右侧：

展示网站插图或工具界面。

---

# 八、首页模块

首页统一采用以下布局：

```
Hero

↓

Popular Tools

↓

Tool Categories

↓

Featured Tools

↓

Why Seller Toolkit

↓

FAQ

↓

Footer
```

禁止随意增加模块。

---

# 九、工具页面

统一布局：

```
工具标题

↓

工具介绍

↓

输入区域

↓

Generate Button

↓

结果区域

↓

How To Use

↓

FAQ

↓

Related Tools
```

所有工具页面保持一致。

---

# 十、按钮规范

主按钮：

蓝色。

圆角：

8px。

高度：

48px。

Hover：

颜色略深。

禁止使用夸张动画。

---

# 十一、卡片规范

统一：

白色背景。

圆角：

12px。

阴影：

轻微。

Hover：

轻微上浮。

所有工具卡片保持一致。

---

# 十二、图标规范

统一使用：

Lucide Icons

禁止混用多个图标库。

所有图标保持统一风格。

---

# 十三、图片规范

优先 SVG。

避免大量 PNG。

图片必须压缩。

不得影响首页加载速度。

---

# 十四、响应式设计

支持：

Desktop

Tablet

Mobile

所有页面必须响应式。

移动端优先保证：

搜索

工具使用

按钮点击

输入框操作

---

# 十五、SEO 页面规范

每个页面必须包含：

* H1
* Title
* Meta Description
* Breadcrumb（需要时）
* FAQ Schema（工具页）
* Internal Links

不得出现空标题。

---

# 十六、交互规范

用户点击按钮：

立即反馈。

AI 工具：

显示 Loading。

生成完成：

自动滚动到结果。

错误：

显示友好提示。

禁止出现浏览器默认错误。

---

# 十七、未来扩展

后续新增页面必须遵守本规范。

不得单独设计新的页面风格。

保证整个网站视觉统一。

---

# 十八、设计参考

整体设计参考以下风格（仅参考设计理念，不直接复制）：

* Stripe（简洁布局）
* Notion（留白与排版）
* Vercel（现代感）
* Linear（细节）
* Ahrefs（工具型网站）
* Semrush（SEO 工具平台）

目标不是模仿，而是达到同级别的专业感。

---

# 十九、最终设计目标

用户第一次进入网站，应产生以下印象：

> **这是一个专业、可信、速度快、长期维护的国际化工具平台，而不是个人开发的小工具网站。**
