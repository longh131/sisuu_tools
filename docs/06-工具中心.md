---

# Tool Center 开发规范

## 一、定位

Tool Center 是整个网站的核心页面。

作用：

* 展示所有工具
* 提供搜索入口
* 提供分类浏览
* 承担大量 SEO 流量
* 引导用户进入工具详情页

Google 收录重点页面：

```text
/tools
/ai-tools
/calculators
/policy
/resources
```

---

# 二、URL 规划

统一采用静态 URL。

```text
/tools

/tools/ai-tools

/tools/calculators

/tools/policy

/tools/resources
```

不得使用：

```text
/tools?id=1

/tools?page=2
```

分页统一采用：

```text
/tools/page/2
```

---

# 三、页面结构

```text
Header

↓

Page Title（H1）

↓

Page Description

↓

Search Box

↓

Category Tabs

↓

Tool Grid

↓

Pagination

↓

FAQ

↓

Footer
```

所有分类页面保持一致。

---

# 四、顶部介绍

每个分类页面必须包含：

标题（H1）

一句介绍

例如：

## AI Tools

AI-powered tools designed to help eCommerce sellers write faster, respond smarter and improve productivity.

---

# 五、搜索

支持搜索：

* Tool Name
* Amazon
* eBay
* Shipping
* VAT
* Profit
* Review

第一版：

前端过滤即可。

后期：

数据库搜索。

---

# 六、分类导航

固定显示：

```text
All Tools

AI Tools

Calculators

Policy Center

Seller Resources
```

点击分类无需刷新整个网站。

采用统一页面模板。

---

# 七、工具展示

统一采用 Card。

每个 Card 包含：

* Icon
* Tool Name
* Short Description
* Category
* Free 标签（可选）
* AI 标签（可选）
* Open Tool 按钮

所有卡片保持统一高度。

---

# 八、排序

默认排序：

Featured

↓

Popular

↓

Newest

↓

A-Z

后期支持：

Most Used

Highest Rated

---

# 九、分页

每页：

12 个工具。

分页：

```text
Previous

1

2

3

Next
```

URL 可直接访问。

---

# 十、工具详情跳转

点击任何工具：

进入：

```text
/tools/tool-slug
```

例如：

```text
/tools/amazon-fee-calculator

/tools/vat-calculator

/tools/negative-review-reply-generator
```

---

# 十一、SEO

每个分类页面：

独立：

* Title
* Description
* H1
* Canonical
* Open Graph
* Breadcrumb
* Schema

Google 可单独收录。

---

# 十二、FAQ

每个分类：

至少：

5 个 FAQ。

例如：

What are Seller Tools?

Are these tools free?

Do I need an account?

Can I use these tools for Amazon?

How often are tools updated?

支持 FAQ Schema。

---

# 十三、相关推荐

页面底部：

展示：

6 个热门工具。

形成网站内链。

提升 SEO。

# 十六、开发原则

新增工具时：

只需增加数据库记录。

Tool Center 自动读取并展示。

不得修改页面布局。

不得新增不同样式。

所有工具统一展示方式。

---

# 十七、最终目标

Tool Center 必须成为整个网站的核心入口。

用户可以在 10 秒内找到所需工具。

Google 可以高效抓取所有工具页面。

后续新增 100+ 工具无需修改 Tool Center 页面，仅增加数据即可自动展示。
