# 02-网站结构.md

# 网站结构设计（Website Architecture）

Version：V1.0

---

# 一、网站定位

网站名称：

**Seller Toolkit**

定位：

全球跨境电商卖家工具平台（Global Seller Toolkit）

网站不是 AI 网站，而是专业工具网站。

AI 仅作为部分工具的能力增强。

---

# 二、网站整体结构

```
Home
│
├── AI Tools
├── Calculators
├── Policy Center
├── Seller Resources
├── Blog
├── About
├── Contact
└── Search
```

---

# 三、首页（Home）

首页作用：

* 展示网站价值
* 推荐热门工具
* 展示工具分类
* 引导用户搜索工具
* 增加 SEO 权重

首页模块：

```
Hero

↓

Search

↓

Popular Tools

↓

Tool Categories

↓

Latest Tools

↓

Why Choose Seller Toolkit

↓

FAQ

↓

Footer
```

---

# 四、工具中心（Tools）

所有工具统一放入 Tools。

```
Tools

├── AI Tools
├── Calculators
├── Policy
├── Listing
├── Shipping
├── Finance
├── Marketing
└── Utilities
```

以后新增工具，不修改网站架构。

仅增加工具页面。

* Shopify

* Templates

---

# 九、Blog

博客不追求数量。

只发布高质量内容。

内容方向：

* Seller Guides
* Amazon Tips
* eCommerce Tutorials
* Policy Updates
* Case Studies

所有文章服务于工具页面，引导用户使用工具。

# 十、工具详情页（统一模板）

所有工具采用统一页面结构：

```
工具标题（H1）

↓

工具介绍

↓

输入区域

↓

结果区域

↓

AI 分析（可选）

↓

使用说明

↓

常见问题（FAQ）

↓

相关推荐

↓

Footer
```

统一模板便于维护和 SEO。

---

# 十一、搜索功能

全站统一搜索。

支持：

* 工具名称
* 平台名称
* 功能关键词

未来可扩展 AI 搜索。

---

# 十二、后台管理

后台仅管理员使用。

功能包括：

* 工具管理
* 文章管理
* 分类管理
* SEO 管理
* 用户管理（后期）
* AI 配置
* 系统设置

后台语言使用中文。

---

# 十三、URL 规范

统一采用 SEO 友好结构。

示例：

```
/

首页

/tools

工具中心

/tools/amazon-fee-calculator

/tools/fba-profit-calculator

/tools/negative-review-reply

/policy/amazon

/blog/

/about

/contact
```

禁止使用：

```
?id=1

?page=2

?tool=123
```

---

# 十四、扩展原则

以后所有新增功能：

✔ 不修改导航结构

✔ 不修改目录结构

✔ 不修改 URL 规则

仅增加新的工具页面或内容页面。

保证项目长期稳定发展。
