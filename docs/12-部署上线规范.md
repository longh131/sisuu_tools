# 五、Nginx

反向代理

---

# 六、HTTPS

Let's Encrypt。

自动续期。

强制HTTPS。

开启HTTP/2。

---

# 七、Docker

启动命令：

```bash
docker compose up -d --build
```

更新：

```bash
docker compose down
docker compose up -d --build
```

禁止直接修改容器。

所有修改通过源码重新构建。
